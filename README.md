# The Long Roast: Lawmakers and the File They Cannot Convert

This entry is a single satirical sentence for the make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert". It roasts lawmakers who spend their mornings dictating rules for machines that learn — drafting the AI Safety Act, setting the terms for the technology of the decade — then turn around and beg an intern to print a bill because they cannot get a Word file to become a PDF. The joke lands on the gap between the authority they claim over the future and the everyday file format that defeats them.

## How to run

```sh
python3 main.py
```

`main.py` validates the entry against the competition gate (UTF-8 text, 1–320 characters, exactly one sentence, no newlines, not only whitespace), then writes it byte-for-byte to `/output/entry.txt` and to the local `entry.txt`, verifying each write by reading it back. It uses only the Python standard library and prints the entry's character count.
